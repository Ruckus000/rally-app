# What the model is supposed to say, so a change to either prompt can be
# measured rather than argued about.
#
#   Title | Category | expect-verdict | expect-band
#
# Bands, not exact numbers: two separate inferences will not agree on a
# boundary even at temperature 0, and the rubric only ever promised a tier.
# `-` where the column is not the point of the row. `?` marks a judgment call —
# a row sitting on a boundary the prompt itself draws. Those are reported
# separately and never counted as failures; a `?` going the other way is an
# argument about the prompt's wording, not a wrong answer.
#
# Read by `npm run goals:eval`, and by `npm run goals:rate -- --file=` which
# ignores every column after the category.
#
# Titles are 8-50 characters because that is what `rate-goal` accepts. The two
# rows that break that rule do it on purpose and say so.

# ---------------------------------------------------------------- pricing
# 10-20: vague, or too small to shape a week. The first three are the rubric's
# own worked examples, so a miss here is a prompt not being followed rather
# than a matter of taste.
Get fitter this week | Fitness | ok | 10-20
Drink more water daily | Home | ok | 10-20
Be more productive at work | Work | ok | 10-20
Spend more time with family | Home | ok | 10-20

# 25-35: a real, checkable commitment of ordinary size.
Walk 30 minutes every morning | Fitness | ok | 25-35
Cook at home four nights | Home | ok | 25-35
Journal for ten minutes each night | Mind | ok | 25-35
Call my sister on Wednesday | Home | ok | 25-35

# 40-50: checkable and genuinely demanding, or on a hard deadline.
Bike to work three days | Fitness | ok | 40-50
Run 25 miles across the week | Fitness | ok | 40-50
Deep clean the whole flat by Sunday | Home | ok | 40-50
Meditate 20 minutes every single day | Mind | ok | 40-50

# 55-60: week-defining. The rubric says "reserve this", which is three
# downward pressures against one upward permission, so under-use here is the
# failure to watch for.
Run a half marathon on Sunday | Fitness | ok | 55-60
Write chapter four of the thesis | Work | ok | 55-60
Make thirty cold sales calls | Work | ok | 55-60
Strip and repaint the entire kitchen | Home | ok | 55-60

# ---------------------------------------------------------------- traps
